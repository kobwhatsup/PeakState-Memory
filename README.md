# PeakState AI 记忆系统

PeakState精力管理平台的AI记忆系统实现。

## 项目概述

本项目实现了一个三层混合式记忆架构，让AI助手"楷"能够记住用户的核心信息、近期互动和长期历史，从而提供更个性化、更有温度的服务。

## 架构设计

### 三层记忆架构

1. **第一层：核心身份档案** (Core Identity Profile)
   - 用户基本信息、核心目标、健康信息
   - PostgreSQL JSONB存储
   - 高优先级，低频更新

2. **第二层：情境记忆流** (Contextual Memory Stream)
   - 近期对话摘要、生理事件、情绪记录
   - 向量数据库存储（计划使用Weaviate）
   - 时效性高，中频调用

3. **第三层：长期知识库** (Long-term Knowledge Base)
   - 所有历史对话、数据、故事
   - 向量数据库 + MongoDB备份
   - 海量存储，按需调用

### 第一阶段：MVP（1-2个月）
- ✅ 技术设计文档
- ✅ 任务清单

### 第三阶段：深度整合（6-9个月）

## 技术栈

- **后端**: FastAPI + SQLAlchemy
- **数据库**: PostgreSQL (核心档案) + 向量数据库 (记忆)
- **LLM**: Anthropic Claude Sonnet 4.5
- **嵌入模型**: OpenAI text-embedding-3-small
- **部署**: Docker + 阿里云ECS
